SnippingSoul Mobile

Le bot et ta licence, sans historique ajouté. Prototype à tester sur Chrome iPhone et Android.

  1. Crée un favori dans Chrome, puis appelle-le SnippingSoul Mobile.
  2. Modifie son adresse et colle le code complet, en conservant javascript:.
  3. Ouvre la Web App EA et son marché des transferts.
  4. Lance le favori depuis ce même onglet, puis saisis ta clé.

La clé est envoyée à LicenseGate et n’est pas enregistrée par l’adaptateur mobile. Les réglages restent dans le stockage du site EA. Pour arrêter complètement le signet, actualise la page.

Le bot ne démarre aucun achat avant ton action. Son fonctionnement réel sur téléphone reste à valider. Les sources de prix externes peuvent être bloquées sur mobile.
